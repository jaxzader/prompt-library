# Prompt Library

Custom AI assistants I've designed, tested, and refined using Claude Projects. Each folder holds the system instructions for one assistant, what it's for, and how I built and improved it.

I treat these like small products: define the job, write the instructions, test them on real inputs, and revise when the output misses.

## Assistants

| Assistant | What it does |
|---|---|
| [Job Application Coach](job-application-coach/) | Reads a job posting and produces keyword analysis, tailored resume bullets, a cover letter, an outreach email, and interview prep |
| *More coming* | Daily scheduling planner, task-organization tool, personal coach |

## How I build and test them

1. **Define the job.** What input goes in, what output should come out, and who uses it.
2. **Write the instructions.** Role, rules, constraints, and a fixed output format so results stay consistent.
3. **Test on real inputs.** I run each assistant on real tasks (for example, actual job postings) and check the output for accuracy, tone, and missing pieces.
4. **Iterate.** When output drifts, I tighten the rules. Examples: banning generic AI phrases, requiring every claim to come from real experience, and forcing a consistent section order.
